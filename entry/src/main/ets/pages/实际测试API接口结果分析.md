**接口**: `POST /v1/images/upload`

**测试结果**: ⚠️ **无法测试（文件读取失败）**

**问题描述**: 
- 用户选择了图片，但无法读取媒体库文件
- 错误信息：`Error: No such file or directory`

**根本原因**:
- HarmonyOS 的媒体库文件 URI (`file://media/Photo/...`) 是受保护的路径，无法直接通过 `fileIo` 访问
- 需要使用 HarmonyOS 媒体库 API 的正确方法来获取文件内容
- 可能需要申请 `ohos.permission.READ_MEDIA` 权限

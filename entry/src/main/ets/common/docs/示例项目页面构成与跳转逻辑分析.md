### 2. 页面详细构成

#### 2.1 启动流程页面

##### 2.1.1 Launch Screen (启动页)
- **路由**: `launch`
- **功能**: 
  - 显示启动画面（3秒后自动跳转到登录页）
  - 品牌展示
- **跳转逻辑**: 
  - `launch` → `login` (3秒后自动)

##### 2.1.2 Welcome Page (欢迎页)
- **路由**: `welcome`
- **功能**: 
  - 欢迎引导页面
  - 介绍应用功能
- **跳转逻辑**: 
  - `welcome` → `quiz` (点击"开始使用")
  - `welcome` → `workspace` (点击"跳过")

##### 2.1.3 Login Page (登录页)
- **路由**: `login`
- **功能**: 
  - 手机号登录
  - 微信登录
  - 游客模式
  - 验证码登录
- **跳转逻辑**: 
  - 新用户: `login` → `quiz` → `ai-recommendation` → `home`
  - 老用户: `login` → `home`
  - 微信登录: `login` → `home` (通常不是新用户)
  - 游客模式: `login` → `home`

##### 2.1.4 AI Quiz (AI问卷页)
- **路由**: `quiz`
- **功能**: 
  - AI智能问卷
  - 收集用户偏好
- **跳转逻辑**: 
  - `quiz` → `ai-recommendation` (完成问卷)
  - `quiz` → `home` (跳过)

##### 2.1.5 AI Recommendation (AI推荐页)
- **路由**: `ai-recommendation`
- **功能**: 
  - 显示AI推荐场景
  - 匹配度显示
- **跳转逻辑**: 
  - `ai-recommendation` → `workspace` (立即上传)
  - `ai-recommendation` → `home` (跳过)

---

#### 2.2 主功能页面（Tab页面）

##### 2.2.1 Home Page (首页 - Tab 0)
- **路由**: `home`
- **Tab索引**: 0
- **功能**: 
  - 快速场景选择（淘宝、抖音、小红书、亚马逊、自定义、批量处理）
  - 会员订阅横幅
  - 最近作品展示
  - 查看全部作品按钮
- **跳转逻辑**: 
  - 点击场景 → `scene-detail` (场景详情)
  - 点击"批量处理" → `batch` (批量处理页)
  - 点击会员横幅 → `subscription` (会员订阅)
  - 点击最近作品 → `result` (结果展示页)
  - 点击"查看全部" → `works` (切换到Tab 2)

##### 2.2.2 Scenes Page (场景页 - Tab 1)
- **路由**: `scenes`
- **Tab索引**: 1
- **功能**: 
  - 显示"敬请期待"占位页
  - 场景库功能开发中
- **跳转逻辑**: 
  - 暂无（占位页）

##### 2.2.3 Works Gallery Page (作品页 - Tab 2)
- **路由**: `works`
- **Tab索引**: 2
- **功能**: 
  - 作品列表展示
  - 筛选功能（全部、淘宝、抖音、小红书、亚马逊、自定义）
  - 选择模式（多选、删除、分享）
  - 开始处理按钮
- **跳转逻辑**: 
  - 点击作品 → `result` (结果展示页)
  - 点击"开始处理" → `workspace` (工作台)

##### 2.2.4 User Profile Page (我的 - Tab 3)
- **路由**: `profile`
- **Tab索引**: 3
- **功能**: 
  - 用户信息展示
  - 用户统计数据（已处理、剩余次数、剩余天数）
  - 会员状态显示
  - 菜单列表：
    - 我的作品 → `works` (切换到Tab 2)
    - 订单管理
    - 邀请好友
    - 客服支持
    - 设置 → `settings`
    - 关于我们
  - 退出登录
- **跳转逻辑**: 
  - 点击"设置" → `settings`
  - 点击"升级会员" → `subscription`
  - 点击"我的作品" → `works` (切换到Tab 2)
  - 退出登录 → `login`

#### 2.3 功能页面（非Tab页面）

##### 2.3.1 Workspace (工作台)
- **路由**: `workspace`
- **功能**: 
  - 图片上传
  - 工具选择（上传、抠图、背景、光效、尺寸、滤镜）
  - 图片编辑
  - 应用/导出功能
  - 撤销/重做
  - 云端导入
- **跳转逻辑**: 
  - 点击"应用" → `result` (结果展示页)
  - 点击"导出" → 导出功能（弹窗提示）

##### 2.3.2 Batch Processing (批量处理)
- **路由**: `batch`
- **功能**: 
  - 批量图片上传
  - 批量处理进度
  - 处理状态管理
- **跳转逻辑**: 
  - 处理完成后 → `result` (结果展示页)

##### 2.3.3 Result Display (结果展示)
- **路由**: `result`
- **功能**: 
  - 处理前后对比
  - 分享功能
  - 重新处理
  - 调整参数
  - 保存到作品库
  - 继续处理
  - 批量结果选择
- **跳转逻辑**: 
  - 点击"重新处理" → `workspace`
  - 点击"调整" → `workspace`
  - 点击"保存" → `works` (切换到Tab 2)
  - 点击"继续处理" → `workspace`
  - 返回 → `goBack()`

##### 2.3.4 Scene Detail (场景详情)
- **路由**: `scene-detail`
- **功能**: 
  - 场景详情展示
  - 预览功能
  - 开始处理按钮
- **跳转逻辑**: 
  - 点击"开始处理" → `result` (或 `workspace`)
  - 返回 → `goBack()`

##### 2.3.5 Background Templates (背景模板)
- **路由**: `background-templates`
- **功能**: 
  - 背景模板选择
  - 搜索功能
  - 筛选功能
  - 多选模式
- **跳转逻辑**: 
  - 选择模板后 → `workspace`
  - 返回 → `goBack()`

##### 2.3.6 Subscription (会员订阅)
- **路由**: `subscription`
- **功能**: 
  - 会员套餐展示
  - 订阅功能
  - 价格对比
- **跳转逻辑**: 
  - 返回 → `goBack()`
  - 显示顶部导航栏

##### 2.3.7 Settings (设置)
- **路由**: `settings`
- **功能**: 
  - 账户设置
  - 会员续费
  - 画质设置
  - 清除缓存
  - 升级存储
  - 帮助中心
  - 意见反馈
  - 关于我们
  - 退出登录
- **跳转逻辑**: 
  - 点击"会员续费" → `subscription`
  - 点击"升级存储" → `subscription`
  - 退出登录 → `login`
  - 返回 → `goBack()`
  - 显示顶部导航栏

### 3. 导航系统架构

#### 3.1 导航状态管理

```typescript
interface NavigationState {
  currentRoute: Route;
  history: Route[];
  sceneId?: string;
  workId?: string;
}
```

#### 3.2 认证状态管理

```typescript
interface AuthState {
  isLoggedIn: boolean;
  isNewUser: boolean;
  userId?: string;
  userName?: string;
  userAvatar?: string;
}
```

#### 3.3 核心导航方法

1. **navigateTo(route, params)**: 导航到指定路由
2. **goBack()**: 返回上一页
3. **handleTabChange(tabIndex)**: 切换Tab
4. **handleLoginSuccess()**: 处理登录成功
5. **handleLogout()**: 处理退出登录

home → batch → result
home → subscription
works → result

profile → settings

## 📝 补充建议

### 1. 创建TopNavBar组件

如果当前项目没有TopNavBar组件，建议创建：

```typescript
// common/components/TopNavBar.ets
@Component
export struct TopNavBar {
  @Param title: string = '';
  @Param showBack: boolean = true;
  private routerService: RouterService = RouterService.getInstance();

  build() {
    Row() {
      if (this.showBack) {
        Image($r('app.media.back_icon'))
          .onClick(() => {
            this.routerService.goBack();
          })
      }
      Text(this.title)
        .fontSize(18)
        .fontWeight(FontWeight.Medium)
    }
    .width('100%')
    .height(56)
    .padding({ left: 16, right: 16 })
    .backgroundColor('#FFFFFF')
    .border({ bottom: { width: 1, color: '#E5E7EB' } })
  }
}
```

---

### 2. 统一TabBar使用

确保所有Tab页面都使用TabBar组件，并根据RouterService判断是否显示：

```typescript
// 在BackgroundTemplates.ets, MyWorks.ets, My.ets中
if (this.routerService.shouldShowTabBar()) {
  TabBar()
}
```

---

### 3. 统一路由调用

将所有页面的路由调用统一使用RouterService：

```typescript
// ❌ 旧方式
router.pushUrl({ url: 'pages/Workbench' });

// ✅ 新方式
RouterService.getInstance().navigateTo('pages/Workbench');
```

```
启动流程:
```

## 🔧 使用示例

### 1. 基本导航

```typescript
import { RouterService } from '../common/services/RouterService';

// 导航到指定页面
RouterService.getInstance().navigateTo('pages/Workbench', { imageId: '123' });

// 返回上一页
RouterService.getInstance().goBack();

// 切换Tab
RouterService.getInstance().switchTab(0); // 切换到首页
```

### 2. Tab导航

```typescript
// 在Index.ets中
.onClick(() => {
  this.currentTab = 0;
  this.routerService.switchTab(0).catch((err: Error) => {
    console.error(`切换Tab失败: ${err.message}`);
  });
})
```

### 3. 登录流程

```typescript
// 在Login.ets中
async handleLoginSuccess(isNewUser: boolean) {
  if (isNewUser) {
    // 新用户：跳转到AI问卷页
    await this.routerService.navigateTo('pages/AIQuestionnaire', undefined, true);
  } else {
    // 老用户：直接跳转到主页
    await this.routerService.navigateTo('pages/Index', undefined, true);
  }
}
```

## 📝 路由规范

### 1. 使用RouterService导航

```typescript
// ✅ 正确
RouterService.getInstance().navigateTo('pages/Workbench', { imageId: '123' });

// ❌ 错误
router.pushUrl({ url: 'pages/Workbench' });
```

### 2. Tab切换

```typescript
// ✅ 正确
RouterService.getInstance().switchTab(0);

// ❌ 错误
router.pushUrl({ url: 'pages/Index' });
```

### 3. 返回上一页

```typescript
// ✅ 正确
RouterService.getInstance().goBack();

// ❌ 错误
router.back();
```

### 4. 路由参数

```typescript
// ✅ 正确
RouterService.getInstance().navigateTo('pages/ScenarioDetail', {
  sceneId: 'taobao',
  sceneType: 'ecommerce'
});

// ❌ 错误
router.pushUrl({
  url: 'pages/ScenarioDetail',
  params: { sceneId: 'taobao' }
});
```

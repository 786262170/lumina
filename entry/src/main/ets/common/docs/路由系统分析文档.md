## 📊 参考项目路由系统分析

### 1. 路由架构

参考项目使用**自定义路由系统**，基于React状态管理实现：

- **核心组件**: `AppNavigation` (`src/app/components/app-navigation.tsx`)
- **路由类型**: TypeScript类型定义，包含所有页面路由
- **状态管理**: 使用React Hooks管理路由状态和历史栈
- **Tab导航**: 集成在路由系统中，4个Tab对应不同路由

### 2. 路由类型定义

```typescript
export type Route =
  | 'launch'              // 启动页
  | 'welcome'              // 欢迎页
  | 'login'               // 登录页
  | 'quiz'                // AI问卷页
  | 'ai-recommendation'   // AI推荐页
  | 'home'                // 首页（Tab 0）
  | 'scenes'              // 场景页（Tab 1）
  | 'workspace'           // 工作台
  | 'batch'               // 批量处理
  | 'result'              // 结果展示
  | 'works'               // 作品库（Tab 2）
  | 'profile'             // 我的（Tab 3）
  | 'subscription'        // 会员订阅
  | 'settings'            // 设置
  | 'scene-detail'        // 场景详情
  | 'background-templates'; // 背景模板
```

### 3. Tab导航配置

```typescript
const TAB_CONFIG = [
  { id: 0, route: 'home', label: '首页', icon: Home },
  { id: 1, route: 'scenes', label: '场景', icon: Layers },
  { id: 2, route: 'works', label: '作品', icon: Image },
  { id: 3, route: 'profile', label: '我的', icon: User },
];
```

### 4. 路由流程

#### 4.1 首次启动流程

```
launch (3秒) 
  → login 
    → (新用户) quiz 
      → ai-recommendation 
        → home
    → (老用户) home
```

#### 4.2 登录流程

- **新用户**: `login` → `quiz` → `ai-recommendation` → `home`
- **老用户**: `login` → `home`
- **微信登录**: `login` → `home` (直接登录)
- **游客模式**: `login` → `home` (直接登录)

#### 4.3 Tab切换流程

- Tab切换时，路由切换到对应的Tab路由
- 维护Tab状态，确保Tab高亮正确

### 5. 路由历史管理

- **历史栈**: 使用数组维护路由历史
- **返回功能**: 从历史栈中弹出上一个路由
- **导航方法**:
  - `navigateTo(route, params)`: 推入新路由
  - `goBack()`: 返回上一页

### 6. 条件显示规则

#### 6.1 隐藏Tab栏的路由

```typescript
const HIDE_TAB_BAR_ROUTES: Route[] = [
  'launch',
  'welcome',
  'login',
  'quiz',
  'ai-recommendation',
  'workspace',
  'batch',
  'scene-detail',
  'result',
  'subscription',
  'settings',
  'background-templates',

```

#### 6.2 显示顶部导航栏的路由

```typescript
const SHOW_TOP_NAV_ROUTES: Route[] = [
  'subscription',
  'settings',
];
```

### 7. 路由参数传递

- **场景ID**: `sceneId` - 用于场景详情页
- **作品ID**: `workId` - 用于结果展示页
- **其他参数**: 通过路由参数对象传递

### 8. 页面渲染逻辑

每个路由对应一个页面组件，通过`switch`语句渲染：

```typescript
switch (navState.currentRoute) {
  case 'launch':
    return <LaunchScreen />;
  case 'login':
    return <LoginPage onLogin={...} />;
  // ... 其他路由
}
```

## 📊 当前项目路由系统分析

### 1. 当前实现方式

- **路由API**: 使用HarmonyOS的`@ohos.router`模块
- **路由定义**: `main_pages.json`中定义所有页面
- **导航方法**: 
  - `router.pushUrl()`: 推入新页面
  - `router.replaceUrl()`: 替换当前页面
  - `router.back()`: 返回上一页

### 2. 当前路由列表

```json
{
  "src": [
    "pages/Splash",           // 启动页
    "pages/Welcome",          // 欢迎页
    "pages/AIQuestionnaire",  // AI问卷页
    "pages/AIRecommendation", // AI推荐页
    "pages/Login",            // 登录页
    "pages/Index",            // 首页
    "pages/ScenarioDetail",   // 场景详情
    "pages/Workbench",        // 工作台
    "pages/ProcessResult",    // 结果展示
    "pages/BatchProcess",     // 批量处理
    "pages/MyWorks",          // 作品库
    "pages/My",               // 我的
    "pages/MemberSubscription", // 会员订阅
    "pages/Settings",          // 设置
    "pages/BackgroundTemplates", // 背景模板
    "pages/BackgroundTemplateDetail" // 背景模板详情
  ]
}
```

### 3. 当前问题

1. **缺少统一路由管理**
   - 路由逻辑分散在各个页面
   - 没有统一的路由服务

2. **Tab导航不完整**
   - Tab切换逻辑在Index.ets中，但不完整
   - 没有Tab状态管理
   - Tab切换时路由跳转不一致

3. **缺少路由流程控制**
   - 没有新用户/老用户流程区分
   - 没有路由历史管理
   - 登录后直接跳转，缺少问卷流程

4. **缺少条件显示逻辑**
   - 没有统一的Tab栏显示/隐藏规则
   - 没有顶部导航栏显示规则

5. **路由参数传递不规范**
   - 参数传递方式不统一
   - 缺少参数类型定义

## 📝 路由使用规范

### 1. 使用RouterService导航

```typescript
// ✅ 正确
RouterService.getInstance().navigateTo('pages/Workbench', { imageId: '123' });

// ❌ 错误
router.pushUrl({ url: 'pages/Workbench' });
```

### 2. Tab切换

```typescript
// ✅ 正确
RouterService.getInstance().switchTab(0); // 切换到首页

// ❌ 错误
router.pushUrl({ url: 'pages/Index' });
```

### 3. 返回上一页

```typescript
// ✅ 正确
RouterService.getInstance().goBack();

// ❌ 错误
router.back();
```

### 4. 路由参数

```typescript
// ✅ 正确
RouterService.getInstance().navigateTo('pages/ScenarioDetail', {
  sceneId: 'taobao',
  sceneType: 'ecommerce'
});

// ❌ 错误
router.pushUrl({
  url: 'pages/ScenarioDetail',
  params: { sceneId: 'taobao' }
});
```

## 🎨 UI状态管理

### 1. Tab栏显示/隐藏

```typescript
shouldShowTabBar(): boolean {
  const hideRoutes = [
    'pages/Splash',
    'pages/Welcome',
    'pages/Login',
    'pages/AIQuestionnaire',
    'pages/AIRecommendation',
    'pages/Workbench',
    'pages/BatchProcess',
    'pages/ScenarioDetail',
    'pages/ProcessResult',
    'pages/MemberSubscription',
    'pages/Settings',
    'pages/BackgroundTemplates',
  ];
  return !hideRoutes.includes(this.currentRoute);
}
```

### 2. 顶部导航栏显示

```typescript
shouldShowTopNav(): boolean {
  return ['pages/MemberSubscription', 'pages/Settings'].includes(this.currentRoute);
}
```

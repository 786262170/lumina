## ⚠️ 需要补充项

### 1. 顶部导航栏组件统一化

**当前状态**: 
- 各个页面（Settings、MemberSubscription等）都自己实现了顶部导航栏
- 代码重复，维护困难

**建议方案**:
创建统一的 `TopNavBar` 组件，在需要显示顶部导航栏的页面中复用。

**需要创建的组件**:
```typescript
// common/components/TopNavBar.ets
@Component
export struct TopNavBar {
  @Param title: string = '';
  @Param showBack: boolean = true;
  private routerService: RouterService = RouterService.getInstance();

  build() {
    Row() {
      if (this.showBack) {
        Button() {
          Text('<')
            .fontSize(20)
            .fontWeight(FontWeight.Medium)
            .fontColor('#1A1F36')
        }
        .type(ButtonType.Normal)
        .width(40)
        .height(40)
        .backgroundColor('#F8F9FC')
        .borderRadius(8)
        .onClick(async () => {
          await this.routerService.goBack();
        })
      }

      Text(this.title)
        .fontSize(20)
        .fontWeight(FontWeight.Medium)
        .fontColor('#1A1F36')
        .layoutWeight(1)
        .textAlign(TextAlign.Center)
        .margin({ left: this.showBack ? -40 : 0 })
    }
    .width('100%')
    .height(56)
    .padding({ left: 20, right: 20 })
    .backgroundColor('#FFFFFF')
    .border({ width: { bottom: 1 }, color: '#E5E7EB' })
  }
}
```

**需要更新的页面**:
- [ ] `pages/Settings.ets` - 替换自定义顶部导航栏为TopNavBar组件
- [ ] `pages/MemberSubscription.ets` - 替换自定义顶部导航栏为TopNavBar组件
- [ ] 其他需要顶部导航栏的页面

**优先级**: 🔴 高（代码复用，便于维护）
